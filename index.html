Section I: Bezier Curves and Surfaces

Part 1: Bezier curves with 1D de Casteljau subdivision

De Casteljau's algorithm is a recursive one to compute points on a Bezier curve. Given n control points, linearly interpolate between them to compute n - 1 control points at parameter t, where one of the intermediate points = (1 - t)*pi + t*pi+1. This is lerp(pi, pi+1, t). Applying this step recursively leaves us with one single points lying on the Bezier curve at the given parameter t.

My BezierCurve::evaluateStep lerps each adjacent pair of points with the member t, (1-t)*pi + t*pi+1 and returns n - 1 points.

Part 2: Bezier surfaces with separable 1D de Casteljau

A Bezier surface is a Bezier curve of Bezier curves. You run de Casteljau along each row of the control grid at u to get one point per row. Then you can run it on those points at v, and the single point left is the surface point S(u, v).

In my implementation of BezierPatch::evaluateStep,

- evaluateStep is the same lerp step, but t is a parameter and the points are 3D.

- evaluate1D calls evaluateStep repeatedly until one point is left.

- evaluate(u, v) runs evaluate1D at u on each row of controlPoints, then runs evaluate1D at v on the resulting column of points.

Section II: Triangle Meshes and Half-Edge Data Structure

Part 3: Area-weighted vertex normals

In my implementation of Vertex::normal(),

- walk the faces around the vertex with h = h->twin()->next(), skipping boundary faces.

- for each triangle, add cross(p1 - p0, p2 - p0), already area-weighted because its length is twice the area.

- return the normalized sum.

Part 4: Edge flip

My implementation of HalfedgeMesh::flipEdge(...),

- does nothing if either face is a boundary.

- otherwise saves the 6 half-edges, 4 vertices, 4 outer edges, 4 outer twins and 2 faces.

- then reassigns every pointer through setNeighbors, so the edge P–Q becomes R–S. h0 and h1 are reused as new edge.

- vertex, edge and face half-edge pointers are re-set too. Nothing is created or deleted.

Debugging: just using check_for before and after the flip to figure out that one face referenced by 4 halfedges and one by 2, missing a setNeighbors call.

Part 5: Edge split

My implementation of HalfedgeMesh::splitEdge(...),

- does nothing on boundary edges.

- creates one vertex at midpoint, 3 edges, 2 faces, and 6 halfedges.

- rewires everything into four triangle around new vertex M, reusing h0, h1, e0, f0, and f1.

- resets all vertex, edge, and face pointers, w/ M's halfedge along the original edge, returning M.

Implementation has asymmetric reuse - P–M half keeps e0 and h0, and the Q–M half gets a new edge but reuses h1. so h7 gets eMQ while h6 gets the original e0.

Part 6: Loop subdivision for mesh upsampling

My implementation of MeshResampler::upsample(...):

- computes old-vertex positions (1 - n·u)·pos + u·neighborSum into newPosition, and edge-midpoint positions 3/8(A+B) + 1/8(C+D) into Edge::newPosition, all from original mesh.

- splits each original edge (counting the edge list up front so new edges aren't resplit) and marks the new vertex and its two spoke edges as isNew. Then flip every new edge that joins one old and one new vertex.

- then copy each vertex's newPosition into position.

- boundary edges are skipped throughout, so open meshes are not subdivided correctly.

My implementation sets flags outside splitEdge, after the fact - for each of the new vertex's four edges, it checks whether the far endpoint is one of the two original endpoints P or Q.

- if it is, the edge is one half of the original edge, and isNew = false.

- if it isn't, the edge is a spoke to an opposite corner, and isNew = true.

Sharp corners and edges are pulled in the most when upscaling, making the object rounder and seemingly smaller. Could definitely reduce this difference in size by presplitting edges involved with the sharpest corners to make it less necessary to round the object across long edges.

Each face of the default cube is made of two triangles, and there is one edge diagonally through the face. So as the cube is upscaled, each of the two triangles is divided into 4 triangles, and the upscaled cube will be perpetually lopsided.

By splitting the edge diagonal through each of the faces of the cube before upscaling, each of the faces of the cube are now made up of four triangles, so the square faces are evenly divided into 4 parts. Now, when subdividing, the cube becomes a more symmetrical rounded version of itself at each step.
